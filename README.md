# PvZ2 Gardendless para Livecoins

Versión web de **PvZ2 Gardendless** lista para usar con [Livecoins](https://livecoins.onrender.com).

## Cómo se usa

1. Descarga `pvzge-livecoins.zip` desde [Releases](../../releases/latest).
2. Descomprímelo.
3. En Livecoins, pestaña **Juegos → PvZ2 Gardendless**, pulsa **Elegir carpeta** y selecciona la carpeta `pvzge` (la que tiene `index.html`).
4. Pulsa **Ejecutar juego** y entra a un nivel.

Los regalos de TikTok hacen aparecer soles, plantas y zombis dentro del juego.
